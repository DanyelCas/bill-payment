# 💳 Bill Payment - Sistema de Pago de Servicios

Single Page Application (SPA) profesional construida con **Angular 17** para gestionar el pago de facturas de servicios públicos de forma eficiente y segura.

![Angular](https://img.shields.io/badge/Angular-17.0.0-red)
![TypeScript](https://img.shields.io/badge/TypeScript-5.2.2-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Características Principales

- **🔐 Autenticación**: Gestión de accesos con roles de Cliente y Administrador.
- **🔍 Búsqueda Reactiva**: Consulta de facturas por ID con validación en tiempo real.
- **� Procesamiento de Pagos**: Integración con SweetAlert2 para una experiencia de usuario fluida.
- **📱 Responsive Design**: Interfaz moderna optimizada para todos los dispositivos.

---

## 🚀 Inicio Rápido

### 1. Instalación
```bash
git clone <repo-url>
cd bill-payment
npm install
```

### 2. Ejecución (Requiere 2 terminales)

**Terminal 1 (API Mock):**
```bash
npm run mock:api
```

**Terminal 2 (App):**
```bash
npm start
```
Acceso en: `http://localhost:4200`
